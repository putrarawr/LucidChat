# LucidChat AI

LucidChat AI adalah platform percakapan kecerdasan buatan (AI) generasi baru yang menggabungkan berbagai model AI terkemuka (Google Gemini, OpenAI GPT, Anthropic Claude, DeepSeek, Moonshot Kimi, Qwen, dan Meta Llama) dalam satu antarmuka web yang modern, responsif, dan mudah digunakan.

Aplikasi web ini dirancang untuk membantu pengguna dalam menyelesaikan tugas percakapan harian, analisis dokumen dan foto, generasi gambar AI, pencarian berita terkini, hingga simulasi panggilan suara interaktif.

## Fitur Utama

- Akses Multi-Model AI: Memungkinkan pengguna memilih dan mengganti berbagai model AI secara fleksibel dalam satu platform.
- Mode Panggilan Suara Hands-Free: Pengalaman percakapan suara interaktif layaknya panggilan telepon secara real-time dengan sapaan nama pengguna dan karakter suara khusus.
- Pemindaian Dokumen dan Foto (Auto-Scan): Mendukung unggah serta analisis otomatis file dokumen (PDF, Excel, Word, CSV, Teks, Kode) dan foto (PNG, JPG, WebP, GIF) melalui fitur Drag and Drop atau tombol lampiran.
- Perintah Cepat AI (Slash Commands): Akses instan ke fitur spesifik seperti generasi gambar, perbaikan kode, pembuat diagram, dan penjelas konsep dengan mengetikkan simbol slash pada area input.
- Pencarian Web Real-Time (DeepSearch): Integrasi penelusuran informasi web terkini untuk menyajikan data faktual beserta sitasi sumber secara langsung.
- Mode Arena (Perbandingan AI Side-by-Side): Fitur untuk membandingkan respons dari dua model AI yang berbeda secara bersamaan dalam satu layar.
- Visualisasi Artefak dan Pratinjau Kode: Antarmuka terpisah untuk menampilkan komponen web interaktif (HTML/CSS/JS) dan diagram Mermaid.

## Cara Penggunaan di Web

### 1. Memulai Percakapan
- Buka aplikasi LucidChat pada browser web Anda.
- Ketik pertanyaan atau instruksi Anda pada kolom input yang berada di bagian bawah layar.
- Tekan tombol Kirim (ikon panah atas) atau tekan Enter pada keyboard untuk mengirimkan pesan.

### 2. Memilih dan Mengganti Model AI
- Pada kolom input bagian bawah, klik tombol pemilih model yang menampilkan nama model saat ini (default: Gemini 3.6 Flash).
- Pilih tab Model Spesifik untuk memilih model AI tertentu dari provider seperti Google, OpenAI, Anthropic, DeepSeek, Kimi, Qwen, atau Llama.
- Pilih tab Lucid Combo jika ingin menggunakan preset mode khusus (seperti All-in-One, Programming, DeepSearch, atau Reasoning).

### 3. Menggunakan Fitur Unggah File dan Foto (Drag and Drop)
- Melalui Drag and Drop: Tarik file dokumen atau foto dari komputer Anda dan lepaskan di area input chat. Sistem akan otomatis menampilkan area pemindaian dan memproses isi file.
- Melalui Menu Lampiran: Klik ikon klip kertas pada sebelah kanan kolom input untuk membuka menu popover, lalu pilih salah satu opsi:
  - Unggah Dokumen & File: Untuk dokumen PDF, Excel (.xlsx/.csv), Word (.docx), file kode, atau teks.
  - Unggah Foto / Gambar: Untuk file gambar PNG, JPG, WebP, atau GIF.
- Setelah file diunggah, chip indikator file akan muncul dan berubah menjadi tanda centang hijau setelah proses scan selesai.

### 4. Menggunakan Mode Panggilan Suara Hands-Free
- Klik ikon Headphone yang terletak di sebelah kiri tombol Enter pada kolom input.
- Layar panggilan suara interaktif akan terbuka secara penuh.
- AI akan menyapa Anda secara lisan menggunakan nama panggilan Anda.
- Bicara secara langsung tanpa perlu menekan tombol; AI akan mendengarkan, berpikir, dan merespons menggunakan suara lisan secara otomatis.
- Gunakan tombol mikrofon untuk mematikan input suara, tombol speaker untuk mematikan suara AI, atau tombol telepon merah untuk mengakhiri panggilan.

### 5. Menggunakan Perintah Cepat (Slash Commands)
- Ketik karakter slash ( / ) pada kolom input pesan.
- Menu rekomendasi perintah akan muncul secara otomatis. Beberapa perintah yang tersedia meliputi:
  - /image : Untuk membuat ilustrasi atau gambar visual AI.
  - /code : Untuk meminta AI merancang komponen web HTML/CSS/JS interaktif.
  - /diagram : Untuk merancang flowchart atau diagram urutan menggunakan Mermaid.js.
  - /fix : Untuk menganalisis bug dan memperbaiki kesalahan kode.
  - /summarize : Untuk meringkas teks atau dokumen panjang secara padat.
  - /explain : Untuk menjelaskan konsep rumit secara sederhana.
  - /web : Untuk mengaktifkan pencarian web berita terkini.

### 6. Mengaktifkan Pencarian Web Real-Time
- Klik tombol Cari Web di sebelah kiri bawah kolom input hingga status berstatus aktif (berwarna cerah).
- Kirimkan pertanyaan Anda; AI akan secara otomatis menelusuri web terkini dan menyajikan laporan berita beserta sitasi sumber.

### 7. Menggunakan Mode Arena (Bandingkan 2 AI)
- Klik tombol Mode Arena di bagian bawah kolom input.
- Layar percakapan akan terbagi menjadi dua kolom side-by-side.
- Pilih model AI pertama di kolom A dan model AI kedua di kolom B.
- Kirimkan pesan Anda untuk melihat perbedaan analisis dan jawaban dari kedua model secara bersamaan.

### 8. Penyempurnaan Prompt Otomatis (Enhance)
- Setelah mengetikkan draf pertanyaan pada kolom input, tombol Enhance (ikon tongkat sihir) akan muncul secara otomatis.
- Klik tombol Enhance untuk meminta AI memperjelas dan menyusun prompt Anda agar lebih terstruktur sebelum dikirimkan.
